XRCC 4.1.0 Release

September 15, 2026 · 3 min read

New features

  • Project Source
    • Create Project Sources to reuse as context for AI Quiz and AI Characters
    • Upload documents and use AI to extract key information to use in project sources
    • Analyze and reanalyze Project Sources
    • Set source focus and review source revisions / processing warnings
  • Added Quiz object
    • Quiz object
      • Added Quiz Special Object
      • Spawn Quiz object from Asset Panel under Special Object
      • Edit questions in the Quiz Editor Panel
      • Configure runtime quiz panel appearance and theme
    • AI quiz generation
      • Generate questions with AI from Project Sources
      • Generate multiple questions and edit generated results
    • Quiz scoping with AI Character chat
      • Integrate with AI Character for quiz workflows
      • Dynamically scope the quiz question list based on AI Character chat content
  • Added Asset Property editing and file replacement in the Asset Panel
    • Edit asset name, description, tags, and license
    • Replace asset source files for a selected asset
    • Multi-select batch edit with mixed-value support
    • Model pivot recentering and Sketchfab source metadata display
  • Added Behaviour System features
    • Added dynamic-size behaviour blocks
    • Added behaviour block tooltip descriptions
    • Added auto-snap with axis-lock placement
  • Added Runtime Debug Panel for PC and XR to inspect watched variables, change logs, and behaviour warnings in Debug and Play modes
  • Added Capture Thumbnail On Save toggle in Settings

Updated

  • Updated AI Character with advanced settings panel, source grounding, and improved Auto-type prompt generation
  • Updated Poe API key panels to UI Toolkit and prevented duplicate API key names on create
  • Restricted Poe speech-to-text to English, Mandarin, and Cantonese
  • Improved Asset Panel sorting so assets from the same pack are grouped together
  • Updated Asset Inspector, Replace Asset File, License Viewer, and Sketchfab source display UI
  • Required unique names when renaming assets and instances, and kept AI Character instance names in sync
  • Added loading package status text during package load
  • Blocked selected editor operations while a project is saving

Fixed

  • Fixed microphone StartRecording reusing a stale recording file
  • Fixed wand detection for floor and wall layers
  • Fixed player unable to walk up stairs
  • Fixed LaserPointer raycast and highlight to match Wand on floor and wall layers
  • Fixed item tags not displaying correctly in the Item Panel
  • Fixed changing scene failing after loading a packaged model
  • Fixed XR Debug mode returning to home without cleaning up the info wall
  • Fixed light probe groups and startpoint lighting not loading from packages
  • Fixed measurer lines and reporter captured images not clear up in XR mode
  • Fixed behaviours not stopping when changing mode
  • Fixed Save As producing an invalid project archive
  • Fixed Import Package panel scroll lag
  • Fixed MCU setup panel rendering above the fader in XR
  • Fixed file browser restoring a cached path on project save, and UI Toolkit panels remaining open over the file browser
  • Fixed tooltips not cleaning up and the save button showing the wrong icon after save
  • Fixed Dialog panel failing to load during a lag spike
  • Fixed blinker null reference when a model material is missing
