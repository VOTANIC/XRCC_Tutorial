Character

note

Character Blocks are available for Character object type only.

Block NameBlockDescription
Get Character Property

Output different character property.

  • Voice Volume: Number value specifying the voice volume.
  • Voice Timestamp: Number value specifying the voice timestamp.
  • Motion Timestamp: Number value specifying the motion timestamp.
Set Character Property

Set different character property.

  • Voice Volume: Number value specifying the voice volume.
  • Voice Timestamp: Number value specifying the voice timestamp.
  • Motion Timestamp: Number value specifying the motion timestamp.
Is Playing Motion
Output is the character is playing a motion.
Is Playing Voice
Output is the character is playing a voice.
Play Motion

Start playing the specified motion on the character.

  • Motion: Character motion asset.
  • Loop: Boolean value specifying whether the motion play will be looped.
Stop Motion
Stop playing the motion on the character.
Play Voice

Play the specified audio clip asset with lip sync on the character.

  • Audio: Audio clip asset.
  • Volume: Number value specifying the audio play volume.
Stop Voice
Stop the audio clip playing.
