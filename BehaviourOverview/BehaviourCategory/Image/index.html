Image

note

Image Blocks are available for 2D and 3D Image object types only

Block NameBlockDescription
Get Image Property

Output different image property.

  • Two Sided: Boolean value specifying the image is two sided or not.
  • Keep Aspect Ratio: Boolean value specifying the image keep aspect ratio or not.
note

This node only exist for 2D Image object type.

Set Image Property

Set different image property.

  • Two Sided: Boolean value specifying the image is two sided or not.
  • Keep Aspect Ratio: Boolean value specifying the image keep aspect ratio or not.
note

This node only exist for 2D Image object type.

Set Image

Set the image to display.

  • Image: Image asset in the project's asset library.
